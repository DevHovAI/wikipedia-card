# Changelog

## 1.0.0

First release as a standalone card.

- Random article from any Wikipedia language; several languages are mixed at random
- Image, title, short description and the first paragraphs, including life dates in parentheses
- Optional further paragraphs from the following sections, with headings
- Line limit with a fade on the last line, only when text is cut
- Source line with the CC BY-SA 4.0 notice
- All options in the visual card editor
